# SeattleMAGGIC-SR-and-MA
Codes for conducting meta-analysis of the performance of the SHFM and MAGGIC prognostic models for heart failure

This repository contains code for the analysis conducted in “Predicting mortality in heart failure: A systematic review and meta-analysis of the performance of the SHFM and MAGGIC prognostic models”. This research was funded by the National Institute for Health and Care Research (NIHR) School for Primary Care Research [SPCR grant number 661, PIs Kathryn Taylor and Maria Vazquez-Montes]. The scripts are organised into subfolders by the analysis they support (primary, secondary, sensitivity, or meta-regression). The folder “subscripts” contains core scripts for data preparation, functions to estimate missing performance measures, and auxiliary functions to create forest plots. The code requires the raw “FINAL” datasets (after double extraction check-ups) and the “extraMA” datasets (indicators of studies included/excluded in the meta-analysis). These files can be found in the folder “datasets”, where we also provide the list of variables and variable codes (files ‘variables in datafiles.txt’ and ‘Codes in script.docx’, respectively).  
 Data from primary studies are publicly available within the databases Medline, EMBASE, Science Citation Index and SCOPUS. Our search terms included the names of the two models and their abbreviations (‘shfm’, ‘shfs’, ‘maggic’) as well as multiple terms describing heart failure, including combinations of ‘heart’, ‘cardiac’ or ‘myocardial’ with ‘failure’, ‘insufficiency’ or ‘decompensation’. We applied a sensitive search strategy by not including search terms relating to model performance measures. Searches were carried out from the dates the corresponding model development papers were published (2006 for the SHFM; 2013 for the MAGGIC score) to March 2022.
